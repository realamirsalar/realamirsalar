# Hi there, I'm Amirsalar! 👋

### 👨‍💻 About Me
I am a dedicated **Backend Engineer** with a strong focus on building scalable, maintainable, and high-performance applications. I specialize in the **.NET ecosystem** and have a deep passion for implementing robust architectural patterns. 

## ⚙️ What I'm working on
*   Developing enterprise-level APIs with strict Clean Architecture rules.
*   Building dynamic, state-driven frontends using React and Redux Toolkit.
*   Ensuring code reliability through comprehensive testing using **xUnit**, **NSubstitute**, and **Testcontainers**.
*   Deploying and managing services like Redis using **Docker** for seamless development and integration.

- 🏗️ **Core Focus:** Clean Architecture, CQRS, Distributed Caching (Redis), Repository Patterns, and Automated Testing.
- 💻 **Other Backend Skills:** JWT & .NET Identity with permissions, MediatR, FluentValidation, Entity Framework Core, Docker.
- 🧪 **Testing Stack:** xUnit, NSubstitute, FluentAssertions, Bogus, Testcontainers.
- ⚛️ **Frontend Enthusiast:** Building dynamic and responsive UIs using modern React, Vite, and Redux Toolkit.
- 🔨 **Tools:** Visual Studio, VS Code, Postman, Git, Docker, Plesk Hosting
